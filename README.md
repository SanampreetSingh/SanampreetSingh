### ☁️ Cloud IDE: a development workspace in the browser

Every user gets their own isolated Linux container, plus a code editor, file explorer, one-click execution and live preview, all from the browser.

**What it does**

- 🐳 **Isolated Docker sandbox per user**, a personal Linux environment provisioned on demand
- ✍️ **Monaco editor** with tabs, a file explorer (create files and folders, refresh) and `Ctrl+S` saving
- ▶️ **One-click run** (`Ctrl+Enter`) for C++17, Python 3 and Node.js, with starter templates for each
- 🌐 **Live web preview** through a zero-config proxy: run `serve-link <port>` in the shell and preview your app
- 💻 **Interactive container shell** over WebSockets, with reconnect handling
- 🔐 **Email/password and Google OAuth 2.0 sign-in**, with JWT cookie authentication
- 🧭 **Nginx reverse proxy** routing each user's traffic to their own container

**Stack:** React · Vite · Monaco Editor · xterm.js · Tailwind CSS · Redux Toolkit · Node.js · Express · TypeScript · socket.io · node-pty · Docker · Nginx · MongoDB

## 🧭 How I like to work

- **Tests first** for backend logic: red, green, refactor, with the commit history to show it.
- **Understand before accepting.** I use AI tools heavily, but I read every diff, revert what doesn't fit the design, and log my prompts. The goal is code I can explain.
- **Chase root causes.** One image-upload bug turned out to be three stacked problems, and the real culprit was a hardcoded `Content-Type` header breaking multipart requests.
- **Own mistakes in the open.** I document what went wrong and what I changed.
